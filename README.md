# ClimaLite 🌤️
Painel de Consulta Climática Urbana - Projeto Integrador UNIVESP (Polo São José dos Campos).

## 📌 Sobre o Projeto
O **ClimaLite** é uma aplicação web leve e focada na facilidade de uso para consulta de dados meteorológicos em tempo real, utilizando a API pública Open-Meteo.

## 🛠️ Tecnologias Utilizadas
- **Front-End:** HTML5, CSS3, JavaScript (Vanilla)
- **APIs:** Open-Meteo (Geocoding e Weather Forecast)
- **Persistência:** LocalStorage
- **Acessibilidade:** VLibras, Modo Alto Contraste e Navegação por Teclado
- **Controle de Versão:** Git e GitHub

## 📂 Estrutura do Repositório
- `/` - Código-fonte da aplicação web (`index.html`)
- `/relatorios` - Documentação acadêmica, relatórios parciais e capturas de tela.
